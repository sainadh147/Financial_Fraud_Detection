# Financial Fraud Detection with Machine Learning

This project involves the development of a machine learning model using Python and Scikit-learn to detect and classify financial transactions as fraudulent or legitimate. The model was trained using the Logistic Regression algorithm, focusing on accuracy and precision.

## Overview
The primary objective of this project is to identify fraudulent financial transactions. This was accomplished by addressing data imbalance issues, performing minimal data cleaning, and applying Logistic Regression for binary classification.

## Project Highlights
- **Data Cleaning:** Removed duplicate records from the dataset.
- **Data Analysis:** Addressed the issue of imbalanced data, which is common in fraud detection datasets.
- **Data Preprocessing:** Applied undersampling to balance the dataset and ensure unbiased model performance.
- **Model Development:** Used Logistic Regression for classification.
- **Key Tools & Technologies:**
  - **Python**
  - **Scikit-learn**
  - **NumPy & Pandas**
  - **Matplotlib & Seaborn**

## Steps Involved
1. **Data Collection:** Used a labeled dataset containing transaction details and a target variable (`is_fraud`) indicating whether a transaction was fraudulent.
2. **Data Cleaning:** 
   - Removed duplicate records to ensure data quality and consistency.
3. **Data Analysis:**
   - Identified class imbalance in the dataset, where fraudulent transactions were significantly fewer than legitimate ones.
4. **Data Preprocessing:**
   - Applied undersampling to balance the classes by reducing the number of legitimate transaction records.
5. **Model Training:**
   - Trained a Logistic Regression model on the preprocessed data.
6. **Evaluation:**
   - Evaluated the model using metrics like accuracy and precision to assess its performance.
